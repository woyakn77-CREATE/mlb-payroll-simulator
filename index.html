How it works and sources

League average: run multiplier = (league-average payroll / team payroll) ^ k, using the penalty k above average and the bonus k below, then held within the limits.

Salary cap & floor: over the cap, run multiplier = (cap / team payroll) ^ k; under the floor, (floor / team payroll) ^ k; in between, 1.00. The 2026 default cap is MLB's $244M competitive balance tax threshold. The $150M floor default is the minimum-spend level in the players' union's May 2026 bargaining proposal. MLB has no actual floor. 1982 had neither, so its defaults use the same ratios to that year's average payroll.

In every game each team's runs are multiplied by its own run multiplier, and the higher adjusted score wins. This is a thought experiment that compares results to spending, not a talent rating.

Sources: 2026 payroll, MLB Labor Relations figures via USA TODAY; 2026 scores, MLB Stats API (2,429 games). 1982 payroll, Doug Pappas, Baseball Prospectus (average salary x 25, 1982 dollars); 1982 scores, Retrosheet game logs (2,106 games).
